# AutoTechPT | Landing Page

Landing page responsiva, estática e pronta para apresentação, com HTML, CSS e JavaScript, sem build nem backend.

## Como abrir
Abra `index.html` no navegador ou publique todos os ficheiros mantendo a pasta `assets/`.

## Funcionalidades
- Banner principal imediatamente abaixo do cabeçalho
- Cartões de serviços com fotografias fornecidas
- Galeria com ampliação das imagens
- Links WhatsApp pré-preenchidos por serviço
- Menu móvel e barra fixa de contacto em telemóveis
- SEO básico e favicon

## Antes da publicação
Confirme a compatibilidade e disponibilidade de cada serviço com a empresa. As fotografias foram fornecidas pelo solicitante. Não foram inventados morada, avaliações, preços nem horários. As imagens e a identidade visual são utilizadas para demonstração mediante autorização do titular.
